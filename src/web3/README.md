# Web3 知识体系思维导图

## 1. 区块链基础 (Blockchain Fundamentals)
- **共识机制 (Consensus Mechanisms)**: PoW, PoS, DPoS, NPoS, PBFT
- **交易模型 (Transaction Models)**: UTXO, 账户模型 (Account Model)
- **安全性 (Security)**: 哈希算法 (Hashing Algorithms), 数字签名 (Digital Signatures), Merkle 树 (Merkle Tree)
- **代表性公链 (Major Blockchains)**: 比特币 (Bitcoin), 以太坊 (Ethereum), 波卡 (Polkadot), 索拉纳 (Solana), Cosmos

## 2. 智能合约 (Smart Contracts)
- **编程语言 (Languages)**: Solidity (以太坊), Rust (Solana/Polkadot), Move (Aptos/Sui)
- **开发框架 (Development Frameworks)**: Hardhat, Foundry, Anchor (Solana)
- **安全性 (Security)**: 重入攻击 (Reentrancy), 溢出漏洞 (Overflow), 代理合约 (Proxy Contracts)
- **合约升级 (Upgrades)**: 多签治理 (Multisig Governance), 可升级合约 (Upgradeable Contracts)

## 3. Web3 应用 (DApps - Decentralized Applications)
- **去中心化金融 (DeFi - Decentralized Finance)**: AMM (自动做市商), 借贷协议 (Lending Protocols), 衍生品 (Derivatives)
- **NFT (Non-Fungible Tokens)**: ERC-721, ERC-1155, NFT 市场 (Marketplaces)
- **GameFi (区块链游戏)**: Play-to-Earn, 元宇宙 (Metaverse)
- **DAO (去中心化自治组织 - Decentralized Autonomous Organizations)**: 治理代币 (Governance Tokens), 投票机制 (Voting Mechanisms)

## 4. 跨链与互操作性 (Cross-Chain & Interoperability)
- **Polkadot XCMP (跨链消息传递)**
- **Cosmos IBC (互链通信协议)**
- **Layer 2 解决方案 (Layer 2 Solutions)**: Rollups (Optimistic, ZK-Rollups), Plasma

## 5. 去中心化存储 (Decentralized Storage)
- **IPFS (星际文件系统 - InterPlanetary File System)**
- **Filecoin (去中心化存储市场 - Decentralized Storage Market)**
- **Arweave (永久存储 - Permanent Storage)**
- **Storj / Sia (去中心化云存储 - Decentralized Cloud Storage)**

## 6. 密码学 (Cryptography)
- **零知识证明 (Zero-Knowledge Proofs, ZKP)**: SNARKs, STARKs
- **同态加密 (Homomorphic Encryption)**
- **门限签名 (Threshold Signatures, MPC - Multi-Party Computation)**

## 7. 区块链基础设施 (Blockchain Infrastructure)
- **钱包 (Wallets)**: Metamask, Phantom, SubWallet
- **预言机 (Oracles)**: Chainlink, Band Protocol
- **开发工具 (Developer Tools)**: web3.js, ethers.js, Polkadot.js
